# Okam i18n Localization — Implementation Plan (P0 + P1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a "change store logo from the dashboard" feature (P0), then eliminate hardcoded Norwegian from the frontends by routing all user-facing strings through the existing `$i()` engine with German values and fixing the `kr` currency seam (P1).

**Architecture:** Reuse what already exists. Admin (`Web`, Nuxt2) resolves `$i(key)` via `plugins/i18n.js` against `Web/translations/{no,en,de}.ts`, keyed by Vuex `adminLocale` (initialised from `markets[EDITION].locale` → `de` for the CH build). ConsumerWeb (Nuxt3) resolves `$i` via the shared `Core` submodule against `core/translations/*.ts`. So P0/P1 add keys to the catalog each app already reads — no new library, no submodule change for admin strings. P2 (data-driven market registry) and P3 (backend JSON catalog) are separate plans.

**Tech Stack:** Nuxt 2 + Vue 2 (admin `Web`), Nuxt 3 (ConsumerWeb), Jest + @vue/test-utils (`npm test`), Core `$i()` flat-catalog engine, axios, Azure Blob (`WebApiStorage`).

## Global Constraints

- Branch: **`feature/swiss`** in every repo. Never push `master`/`test` or merge to main until Sven says so. Core-submodule edits (P1 consumer keys only) commit on their own Core branch.
- Localize **de-CH first**. Preserve Norwegian (`no`) values 100%; only add German. English (`en`) optional per key.
- **German copy is drafted here, reviewed by Sven before go-live** — mark newly authored `de` values so they are reviewable.
- Admin strings live in **`Web/translations/{no,en,de}.ts`**; consumer strings in **`Core/translations/{no,de,...}.ts`**. Do not invent a new engine.
- Image rules: **JPG/PNG only, max 5 MB, centre-cropped to 500×500 PNG**.
- Store-logo display URL is deterministic: **`https://okamapistorage.blob.core.windows.net/storelogo/{storeId}?v={timestamp}`**, shown only when `store.logoUrl` is truthy.
- Service access in a component: `this._storeService` (from `plugins/global-mixin.js:175` → `new StoreService(this._coreInitializer)`). Upload endpoint: `POST /stores/logo`, FormData fields `Image` (blob) + `NumberId` (storeId). API base: `this.$config.okamApiBaseUrl`. Toast: `this.showToast(message, type)` (`type` = `'success'|'error'`), as used at `pages/admin/discount.vue:414`.

```js
// Pure logo-file validation shared by the dashboard logo card and (later) onboarding.
export const MAX_LOGO_BYTES = 5 * 1024 * 1024 // 5 MB
const ALLOWED_TYPES = ['image/jpeg', 'image/png']

export function validateLogoFile (file) {
  if (!file || !ALLOWED_TYPES.includes(file.type)) {
    return { ok: false, errorKey: 'logo_errorFormat' }
  }
  if (file.size > MAX_LOGO_BYTES) {
    return { ok: false, errorKey: 'logo_errorTooLarge' }
  }
  return { ok: true, errorKey: null }
}
```

```vue
<template>
  <div class="store-card store-logo-card">
    <div class="store-card__header">
      <h3 class="store-logo-card__title">{{ $i('logo_cardTitle') }}</h3>
    </div>

    <div
      class="store-logo-card__dropzone"
      :class="{ 'is-dragging': isDragging, 'has-logo': !!logoUrl }"
      @click="triggerFileInput"
      @dragover.prevent="isDragging = true"
      @dragleave.prevent="isDragging = false"
      @drop.prevent="onDrop"
    >
      <input
        ref="fileInput"
        type="file"
        accept="image/jpeg,image/png"
        class="store-logo-card__input"
        @change="onFileChange"
      >
      <div v-if="isUploading" class="store-logo-card__status">{{ $i('logo_uploading') }}</div>
      <img v-else-if="logoUrl" :src="logoUrl" class="store-logo-card__preview" alt="" @error="logoUrl = null">
      <div v-else class="store-logo-card__placeholder">
        <span class="store-logo-card__icon">↑</span>
        <span>{{ $i('logo_dropHint') }}</span>
      </div>
    </div>

    <ul class="store-logo-card__tips">
      <li>{{ $i('logo_tipSquare') }}</li>
      <li>{{ $i('logo_tipFormats') }}</li>
      <li>{{ $i('logo_tipMaxSize') }}</li>
    </ul>
  </div>
</template>

<script>
import axios from 'axios'
import { validateLogoFile } from '~/utils/logo'

export default {
  name: 'StoreLogoCard',
  props: {
    storeId: { type: [Number, String], required: true }
  },
  data: () => ({ logoUrl: null, isUploading: false, isDragging: false }),
  watch: {
    storeId: { immediate: true, handler () { this.fetchCurrentLogo() } }
  },
  methods: {
    triggerFileInput () { if (this.$refs.fileInput) this.$refs.fileInput.click() },
    onDrop (e) {
      this.isDragging = false
      const file = e.dataTransfer && e.dataTransfer.files && e.dataTransfer.files[0]
      if (file) this.handleFile(file)
    },
    onFileChange (e) {
      const file = e.target.files && e.target.files[0]
      if (file) this.handleFile(file)
    },
    handleFile (file) {
      const { ok, errorKey } = validateLogoFile(file)
      if (!ok) { this.showToast(this.$i(errorKey), 'error'); return }
      this.cropAndUpload(file)
    },
    cropAndUpload (file) {
      const reader = new FileReader()
      reader.onload = (ev) => {
        const img = new Image()
        img.onload = () => {
          const size = 500
          const canvas = document.createElement('canvas')
          canvas.width = size
          canvas.height = size
          const ctx = canvas.getContext('2d')
          const side = Math.min(img.width, img.height)
          const sx = (img.width - side) / 2
          const sy = (img.height - side) / 2
          ctx.drawImage(img, sx, sy, side, side, 0, 0, size, size)
          canvas.toBlob((blob) => this.upload(blob), 'image/png')
        }
        img.src = ev.target.result
      }
      reader.readAsDataURL(file)
    },
    upload (blob) {
      this.isUploading = true
      const formData = new FormData()
      formData.append('Image', blob, 'logo.png')
      formData.append('NumberId', this.storeId.toString())
      const token = this.$store.state.currentUser && this.$store.state.currentUser.token
      axios.post(`${this.$config.okamApiBaseUrl}/stores/logo`, formData, {
        headers: { Authorization: `Bearer ${token}` }
      }).then(() => {
        this.isUploading = false
        this.fetchCurrentLogo()
        this.showToast(this.$i('logo_updated'), 'success')
        this.$emit('logo-updated')
      }).catch(() => {
        this.isUploading = false
        this.showToast(this.$i('logo_errorUpload'), 'error')
      })
    },
    fetchCurrentLogo () {
      if (!this.storeId) return
      this._storeService.Get(this.storeId).then((store) => {
        if (store && store.logoUrl) {
          const ts = new Date().getTime()
          this.logoUrl = `https://okamapistorage.blob.core.windows.net/storelogo/${this.storeId}?v=${ts}`
        } else {
          this.logoUrl = null
        }
      }).catch(() => { this.logoUrl = null })
    }
  }
}
</script>
```

# Phase P1 — Kill the Norwegian leaks (frontend)

**Not 282 micro-tasks** — a repeatable per-string procedure applied in batches by hotspot, plus two discrete infra tasks (a key-coverage guard and the currency seam). Inventory of every string with file:line is in the workflow output (`scratchpad/findings.json`) and the spec §1/§4.

**Per-string migration procedure (the pattern):**
1. Pick the next hotspot file. For each hardcoded Norwegian literal in `<template>`, `alert()`, or bound text:
2. Choose a key: `<area>_<slug>` (e.g. `onboarding_ai_pasteLabel`, `terms_merchant_heading`).
3. Add the key to the app's catalog: **admin →** `Web/translations/{no,en,de}.ts`; **consumer →** `Core/translations/{no,de}.ts`. `no` = the original literal; `de` = drafted German (mark for review); `en` if trivial.
4. Replace the literal with `$i('key')` (or `$i('key', { param })` for interpolation; for `alert(x)` use `alert(this.$i('key'))`).
5. After each file: `cd <repo> && npx jest` stays green; visually check the page renders in German.
6. Commit per file or per small group: `git commit -m "i18n(admin): localize <file>"`.

--- A PRODUCT DEFECT THIS ARM EXPOSED (not fixed here) ----------------------------------------
With NOTHING listening on the API, the login modal still advances to the OTP step and offers six
boxes for a code it never sent. RequestService.PostRequest RESOLVES a failed request to the axios
error object instead of rejecting; UserService.SendVerificationToken turns that into false; and
LoginModal.getCode sets smsSent = true in a .then() that never reads the value. Its
«Feil telefonnummer» arm is therefore unreachable for any server-side failure. Out of this lane's
scope — thirty-one journeys share signIn and none of them is about the modal's honesty.

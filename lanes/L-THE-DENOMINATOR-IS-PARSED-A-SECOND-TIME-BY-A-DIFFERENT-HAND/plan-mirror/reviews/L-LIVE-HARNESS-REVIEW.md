# Fable review — the live-journey harness and its three journeys (2026-08-02)

Read-only. Nothing edited, nothing run.

## Verdict — sound-with-conditions

**The wrong-world guard itself is real and symmetric.** Both halves traced; the fixture's served counter
**genuinely excludes the harness's own control traffic**; the pre-fix hole existed exactly as described —
the old code wrote the artifact and **never re-threw**; and **every artifact the lanes filed matches their
prose to the digit.** The label *live* can no longer be produced without traffic to the declared origin.

**But the artifact store can still lie about the estate's evidence state — and is doing so right now.**

## 1. Can an artifact still say live and be wrong?

**Yes, by staleness.** The write happens only in teardown. A run whose teardown never executes — a kill, a
timeout, or the fixture dying so the stats fetch throws first — **leaves the previous run's artifact
standing, live-labelled and passed**, and **nothing clears the directory at run start.**

**Yes, by overwrite at the join key — and this is live in the repository now.** The contract is one file
per journey, overwritten each run, and in fixture mode the live journeys run too. **Confirmed by direct
check:** the canonical `events-deposit-precondition` artifact is the **deliberately-failed guard proof**,
and both workforce artifacts are the **fixture** confirmation runs. **A probe joining on the canonical path
today finds zero live evidence and one live failure.** The passing live artifacts survive only under the
lanes' own directories. **The strongest evidence a journey ever produced is silently replaced by the
weakest.**

**Yes, on backend identity — the third shape neither lane named.** The health probe is unauthenticated and
its recorded body is one word, so **any API satisfies it**, including a different lane's world or a
checkout several releases old. The staff lane's API was built from a detached worktree and **no artifact
records that anywhere**: the recorded commit is the *frontend* tree. **This is the fixture-version blocker
transferred, not solved** — the live path is genuinely better, and the record still makes an unchecked
claim about which backend answered.

**No** on two shapes: the declared base URL cannot diverge from where the browser went, and no journey is
fully hollow — the flag board **is not optimistic**, it adopts the server's response and re-reads.

**Latent, not live:** the served floor is an existence check, and sign-in alone clears it — so a journey
whose *subject* calls went to a second origin would still pass. No hardcoded origins exist today; it
becomes real the day any client grows its own.

## 3. Defects, most severe first

1. **The artifact store is last-writer-wins with no provenance, and it has already destroyed the program's
   evidence.** Anything promoting on the canonical path **must filter on backend, status, commit and
   recency** or it reads the wrong world's answer.
2. **Stale artifacts survive interrupted runs**, so yesterday's live-and-passed file stands for today's
   broken world.
3. **No backend identity in the artifact.** Until a build is recorded, a live run against a stale backend is
   **indistinguishable** from one against the current one.
4. **A false claim in the seed script:** it says there is no admin create-store endpoint on this branch.
   **There is** — an anonymous registration route that creates both the store and the caller's admin row,
   with a shipped page that calls it, and a market endpoint under admin auth. **So two of the five directly
   inserted tables likely had a product path the seed bypassed** — including the registration flow, which no
   journey exercises. **The workforce trio's unavoidability, by contrast, is verified true:** no controller
   touches the employer table, and creating staff requires a capability resolved from an engagement that does
   not exist yet. One quiet extra: **the manager's fifteen capability grants are themselves an authz-relevant
   write no product surface ever made**, and the wage evidence depends on it.
5. Live mode with no path argument selects all three live journeys into one world, and the second reds as a
   timeout — **an honest red that reads as a product defect**, violating the harness's own fail-with-a-sentence
   law. The older run note even prints the pathless command.
6. Minor: origin comparison is by string, so two spellings of localhost produce a false red — safe direction.
   And a console filter swallows every refusal journey-wide rather than the subject one, mitigated because
   failed requests are still recorded.

## 4. Assertions that could pass against a broken harness

- A cost assertion matching **any digit-bearing string** — it would pass on a zero-priced figure, which is
  exactly the rate-resolution bug it looks like it guards. **The real figure lands only in the step detail.**
- A rule-count assertion of *greater than zero*, where the pack's eleven is recorded but not asserted.
- The moved stamp assertion passes for **any** named actor, **including the wrong one.**
- Both served floors pass on bootstrap traffic alone if subject traffic ever splits origins.
- And the store defects above let **a reader's conclusion** pass against a broken harness even when every
  in-run assertion is sound.

## 5. The four judgements

**Scaling cost — artifact, not inherent.** The unpickability of a written-through world is real and is the
schema working. **But no-reset does not follow:** restore-from-backup is not unpicking, and the from-empty
migration replay — the only genuinely slow part — **proves a property that needs proving once per session,
not once per journey.** Both journeys also pin *the current week* by design; parameterising it would let one
world host several. Correct documentation of today's shape, **wrong as the plan for the larger groups.**

**The seeding shape** — the workforce trio is genuinely unavoidable; **the store pair is not, and the
script's justification for bypassing it is false.**

**"Unfakeable" is too strong; "unfaked, and expensive to fake" is right.** The guard's threat model is
accident, not adversary, and for accident it is sound. **Of the three offers, the two pivot defects
reproducing live are the strongest** — world-independent product facts. The money figure's weight rests on a
reader doing the arithmetic, because the in-run assertion would pass on a wrong figure.

**The moved literal is justified but weaker than it had to be.** Pinning the fixture's actor was
fixture-coupled and correct to move — but *somebody, and not unknown* passes if attribution names **the
wrong somebody.** The strong form exists and holds in both worlds: assert the stamp's actor **equals the
signed-in user's own id.**

## 6. What could not be determined

Whether the fixture-side mutation actually re-ran red — structurally certain from the shared re-throw, taken
on the lane's word. Historical exit codes. Whether the approval flag is required by any surface these
journeys traverse — which decides how much of the seed simplifies. And whether the backend that answered
differs materially from the branch head the frontend commit implies — **which is exactly the point: the
artifact gives a reader no way to ask.**

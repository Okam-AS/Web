    export API_BASE=http://127.0.0.1:5971
    export MANAGER_PHONE=+4799681931 MANAGER_CODE=<this world's demo verification code>
    export STORE_NAME='Two Humans Kafé'

The walk is walk-modules.js in this directory (MANAGER_CODE=... node walk-modules.js [module ...]).
It signs in as the manager and, per page, writes the rendered text plus a full-page screenshot, and
records every console error and every response >= 400. All six pages: zero of each.

Run logs in this directory are kept including the failing ones, which are the receipts for the
defects named in the RETURN.
